# Ayni

**Solana སྟེང་གི་རང་སྲིད་རང་སྐྱོང་གི་མིང་མི་གསལ་བའི་ཚོགས་མི་མཐུན་འབྲེལ་ཚོགས་པ་ — འབྲེལ་མེད་སྦྱར་འཛིན་ (soulbound)། ZK གསང་བ། བདག་པོ་མེད་པ།**

རིག་པ་ཀླད་སྟོང་ (zero-knowledge) གི་མིང་མི་གསལ་བའི་འོས་འདེམས་དང་། འདེམས་གཏོགས་ཀྱིས་གསལ་བཤད་ཐུབ་པའི་བརྒྱུད་རིམ་གྱི་ཡིད་ཆེས་ལག་ཁྱེར་བཅས་དང་ལྡན་པའི་ཚོགས་མི་མཐུན་འབྲེལ་གྱི་ DAO ཡི་ཆེད་དུ་བཀོལ་སྤྱོད་ཁ་ཕྱེ་བའི་སྒྲོམ་གཞི།

## Ayni ནི་གང་ཞིག་ཡིན་ནམ།

Ayni ནི་**མིང་མི་གསལ་བའི་རང་སྲིད་རང་སྐྱོང་གི་རྩ་འཛུགས་ (DAO)** ཞིག་གི་ Solana ལག་ལེན་རྣམ་གཞག་ཡིན་ཏེ་ — ཐོག་མར་**AHA (Ancestral Humanity Anonymous)** ཡི་དགོས་མཁོ་སྐོང་བའི་ཆེད་དུ་བཟོས་པ་ཡིན་ཡང་། རྩ་འཛུགས་གང་རུང་ལ་ཁ་ཕྱེ་བ་ཡིན། དེའི་ངོ་བོ་ནི་འཛམ་གླིང་ཡོངས་ཀྱི་ཚོགས་མི་མཐུན་འབྲེལ་གྱི་ཆེད་དུ་ལྕགས་ཐག་ལ་མ་ལྟོས་པའི་དཔེ་གཞི་ཞིག་ཡིན་ལ། **AA / གོམ་པ་ ༡༢ ཡི་སྲོལ་རྒྱུན་**གྱིས་ལོ་བརྒྱ་མི་ཉམས་པར་མཚོན་པའི་གྲུབ་འབྲས་ལ་དཔེ་བླངས་ཡོད། འདིས་ཚོགས་པ་གང་རུང་ལ་**ཚོགས་མི་འཇུག་པ། མཛོད་ཁང་འཛིན་པ། ཚོགས་པའི་བློ་ཡུལ་ལ་བརྟེན་ནས་ཐག་གཅོད་པ། དེ་བཞིན་བརླག་པའི་ལྡེ་མིག་ལས་སླར་གསོ་བྱེད་པ་**བཅས་ཀྱི་ཐབས་ལམ་གྲ་སྒྲིག་ཟིན་པ་ཞིག་སྟེར་ — དེ་ཡང་ཚོགས་མི་རེ་རེ་ནི་རིག་པ་ཀླད་སྟོང་གི་ར་སྤྲོད་བརྒྱུད་ནས་**གཞི་རྩའི་ཐོག་ནས་མིང་མི་གསལ་བར་**གནས་ཐུབ།

- **དེས་ཅི་བྱེད་དམ་** — ཚོགས་མི་མཐུན་འབྲེལ་ཞིག་ལྕགས་ཐག་སྟེང་དུ་བསྐྱར་བ་སྟེ། ལོ་རེའི་འབྲེལ་མེད་སྦྱར་འཛིན་ཚོགས་མི། མིང་མི་གསལ་བའི་ཚོགས་མི་གཅིག་ལ་འོས་གཅིག མཁོ་སྤྲོད་ཁོ་ནའི་མཛོད་ཁང་། དེ་བཞིན་ལྡེ་མིག་སླར་གསོ་ ༤/༧ ཅན་གྱི་སྡེ་ཚན་ ༧ ཡི་སྒྲིག་ཁྲི་ (Council) ཞིག་སྟེ་ — བདག་པོ་མེད། འཛིན་སྐྱོང་ལྡེ་མིག་མེད།
- **སུ་ཡི་ཆེད་དུ་ཡིན་ནམ་** — ཚོགས་མི་མཐུན་འབྲེལ། ཕན་ཚུན་རོགས་སྐྱོར་ཚོགས་པ། མིང་མི་གསལ་བའི་སྤྱི་ཚོགས། ཚོང་ཟོག་ལྟ་བུར་སྤྲོ་བཤད་ལས་**མཉམ་གཏོགས་**ཀྱི་འདུ་ཤེས་འདོད་པའི་ DAO དང་། ཚོགས་མི་ལ་**གསང་བ་ངོ་མ་**དགོས་མཁན་སུ་རུང་ཡིན།
- **ཇི་ལྟར་བཀོལ་དགོས་སམ་** — དཔེ་གཞི་འདི་ fork བྱས། སྒྲིག་ཁྲི་ཞིག་འཛུགས། སྡེ་ཁོར་ (Circle) ཞིག་ཁ་ཕྱེ། ཚོགས་མི་རྣམས་གསང་བའི་ཁས་ལེན་ (commitment) ལ་འཇུག ལྟོས་ས་ [མགྱོགས་འགོ](#-quick-start)།

> *Ayni* (ཀུ་ཆུ་ཝ་སྐད): སྟེར་བ་དང་ལེན་པའི་དམ་པའི་ཕན་ཚུན་ — རང་རྒྱབ་སྐྱོར། ཚོགས་མི་གཅིག་ལ་སྐད་གཅིག དབུས་ཀྱི་བདག་པོ་མེད།

## ✨ ཁྱད་ཆོས།

- 🪪 **འབྲེལ་མེད་སྦྱར་འཛིན་ཚོགས་མི་** — ལོ་རེ་བཞིན་དང་སྤོ་འགྱུར་མི་ཐུབ་པ། མཉམ་གཏོགས་ནི་འབད་རྩོལ་གྱིས་ཐོབ་ཅིང་བསྐྱར་གསོ་བྱེད་པ་ཡིན་གྱི། ཉོ་ཚོང་གི་གཞི་མ་མིན།
- 🕶️ **གཞི་རྩའི་ཐོག་ནས་མིང་མི་གསལ་བ་** — ཚོགས་མི་ཞིག་ནི་མཐོང་རུང་གི་སྒམ་ (wallet) ཞིག་མིན་པར་ Merkle ཚོགས་ཀྱི་ནང་གི་གསང་བའི་ཁས་ལེན་ཞིག་ཡིན། འོས་འཕེན་དང་ཡིད་ཆེས་ལག་ཁྱེར་ནི་རིག་པ་ཀླད་སྟོང་ཡིན། ངོ་བོ་ནི་རང་འདོད་ཀྱིས་ཁོ་ན་གསལ།
- 🗳️ **ཚོགས་པའི་བློ་ཡུལ་འོས་འདེམས་** — ཚོགས་མི་གཅིག་ལ་འོས་གཅིག་མིང་མི་གསལ་བར་འཕེན་པ་ (token རིན་ཐང་ལ་བརྟེན་པའི་ཕྱུག་པོའི་དབང་སྒྱུར་མེད) ལ། འགྲོས་གཏན་འབེབས་རེ་རེར་nullifier ཞིག་གིས་འོས་ཟློས་མ་འཕེན་པ་སྔོན་འགོག་བྱེད།
- 🏛️ **བདག་པོ་མེད། འཛིན་སྐྱོང་ལྡེ་མིག་མེད་** — སྡེ་ཚན་ ༧ ཅན་གྱི་སྒྲིག་ཁྲི་*ཉིད་*དབང་ཆ་ཡིན་ཞིང་། **༤/༧** ཀྱི་ཐོག་ནས་ཁོ་ན་ལས་ཀ་བྱེད།
- 🔑 **བརླག་པ་ལས་སྐྱོབ་པའི་ལྡེ་མིག་སླར་གསོ་** — སྒྲིག་ཁྲི་ནི་འཁོར་སྐྱོད་བྱེད་པའམ། བརླག་པའི་སྒམ་ཞིག་གི་ཡོ་བྱད་ཡོངས་གསར་པ་ཞིག་ལ་སྤོ་བ། དེ་ཡང་སྒྲིག་ཁྲི་གཅིག་པུ་དྲང་པོ་ཡིན་ན་འགོག་ཐུབ་པའི་རྩོད་ཡུལ་ཡུན་ཚོད་ཀྱི་རྒྱབ་ནས།
- 🌱 **Fork བྱེད་ཐུབ་པའི་སྡེ་ཁོར་** — ཚོགས་པ་གང་རུང་གིས་སྲིད་འཛིན་འདྲ་མཉམ་ལྡན་པའི་སྡེ་ཁོར་གསར་པ་ཞིག་སློང་ཐུབ། འཛམ་གླིང་ཞབས་ཞུ་སྡེ་ཁོར་ (World Service Circle) གྱིས་མཉམ་སྤྱོད་ཀྱི་ཡོ་བྱད་མཐུན་སྒྲིག་བྱེད་ཀྱི་ཡོད་ལ། དབང་སྒྱུར་མི་བྱེད།
- 📜 **འདེམས་གཏོགས་གསལ་བཤད་ཡིད་ཆེས་ལག་ཁྱེར་** — སློབ་ཚན/འགོ་འཛུགས་ལག་ཁྱེར་ ("སུ། སློབ་ཚན་གང་། སུས་བསླབ། ནམ་") ནི་རིག་པ་ཀླད་སྟོང་གི་ཐོག་ནས་*ཁོངས་རེ་རེ་བཞིན་*ཁ་ཕྱེ་བ།

- **ཚོགས་མི་ (ལོ་འདབ)** — རེ་རེ་ནི་སྡེ་ཁོར་ཞིག་གི་ཚོགས་མིའི་ཚོགས་ནང་མིང་མི་གསལ་བའི་ཁས་ལེན་ཞིག་ལ་འཇུག་ཅིང་ར་སྤྲོད་བརྒྱུད་ནས་ལས་ཀ་བྱེད། སྒམ་ཞིག་མཐོང་སར་འདོན་མི་དགོས། ཚོགས་མི་གཅིག་ལ་འོས་གཅིག
- **སྡེ་ཁོར་ (ཡལ་ག)** — རང་སྲིད་རང་སྐྱོང་གི་ས་གནས་ཚོགས་པ། རེ་རེར་རང་གི་སྡེ་ཚན་ ༧ ཅན་གྱི་སྒྲིག་ཁྲི། མཛོད་ཁང་། འོས་འདེམས་ལྡན། དཔེ་གཞི་ལས་ fork བྱས་པ།
- **འཛམ་གླིང་ཞབས་ཞུ་སྡེ་ཁོར་ (སྡོང་པོ/རྩ་བ)** — མཉམ་སྤྱོད་ཀྱི་དཔེ་གཞི་དང་ཡིག་ཆ་འཛིན་ཅིང་སྡེ་ཁོར་གསར་འཛུགས་མཐུན་སྒྲིག་བྱེད། འོན་ཀྱང་ས་གནས་ཚོགས་པའི་བློ་ཡུལ་ལ་**ཟློག** མི་བྱེད། འབྲེལ་མཐུད་འདི་ནི་*མཉམ་འབྲེལ་འབྲེལ་མཐུད་*ཞིག་ཡིན་གྱི། བཀའ་སྒྲིག་གི་ལྕགས་ཐག་མིན།
