## ᓱᓇᐅᕙ Ayni?

Ayni ᑖᓐᔮ Solana-ᒧᑦ ᐊᑐᓕᖅᑎᑕᐅᓂᖓ **ᑭᓇᐅᔭᕈᓐᓃᕐᓂᕐᒥᒃ ᐃᒻᒥᓂᒃ-ᐊᐅᓚᑦᑎᔪᖅ ᑲᑐᔾᔨᖃᑎᒌᒃ (DAO)** —
ᐱᒋᐊᕐᕕᒋᔭᐅᔪᖅ ᑎᑭᑦᑐᕆᔭᐅᓂᐊᕐᓗᑎᒃ ᐱᔪᒪᔭᖏᑦ **AHA (Ancestral Humanity Anonymous)**, ᑭᓯᐊᓂ ᒪᑐᐃᖓᔪᖅ
ᑭᑐᑐᐃᓐᓇᕐᓄᑦ ᑲᑐᔾᔨᖃᑎᒌᓄᑦ. ᓇᒻᒥᓂᖅ ᐅᕙᓂ ᑖᓐᓇ ᐃᒡᓗᕈᓯᕐᒧᑦ ᓱᓇᒥᑦᑐᖃᖏᑦᑐᖅ ᐃᒡᓗᕐᔪᐊᒃᓴᖅ ᓄᓇᕐᔪᐊᕐᒥᐅᓄᑦ
ᐃᓚᒌᓄᑦ, ᒪᓕᒡᓗᒍ ᐊᕐᕌᒍᓄᑦ ᕼᐊᓐᑐᕈᕐᓄᑦ ᓇᓗᓇᐃᖅᑕᐅᓯᒪᔪᖅ ᐱᕙᓪᓕᐊᓂᖓ **AA / 12-ᑎᑎᕋᕐᓂᕆᔭᐅᔪᖅ**.
ᑐᓂᓯᔪᖅ ᑭᑐᑐᐃᓐᓇᕐᓄᑦ ᐱᐊᓂᒃᓯᒪᔪᒥᒃ ᐃᖅᑲᓇᐃᔮᕐᒥᒃ **ᐃᓚᐅᔪᓂᒃ ᐃᓕᓴᕆᔪᓐᓇᖅᑐᑦ, ᑮᓇᐅᔭᐃᑦ ᑎᒍᒥᐊᕐᓗᒋᑦ,
ᑲᑎᒪᔨᒃᑯᑦ ᐃᓱᒪᒋᔭᖏᑦᑎᒍᑦ ᐃᓱᒪᓕᐅᕐᓗᑎᒃ, ᐊᒻᒪᓗ ᑮᓇᐅᔭᕈᑎᑦ ᐊᓯᐅᔨᕝᕕᐅᓂᖏᓐᓂᒃ ᒪᑭᒪᑎᑦᑎᔪᓐᓇᕐᓗᑎᒃ** — ᐃᓚᐅᔪᑦ
ᐊᑕᐅᓯᐊᕐᓗᒋᑦ **ᑭᓇᐅᔭᕈᓐᓃᖅᑐᑦ** ZK-ᓇᓗᓇᐃᔭᐅᑎᑎᒍᑦ.

- **ᓱᓇᒥᒃ ᐱᓕᕆᕙᑦ** — ᐊᐅᓚᑦᑎᔪᖅ ᐃᓚᒌᑦ ᐃᓚᐅᓂᖓ ᓴᕕᕋᔭᒃᑯᕕᖕᒥ: ᐊᕐᕌᒍᑕᒫᑦ ᑖᕐᓂᕈᓐᓇᖏᑦᑐᑦ ᐃᓚᐅᓂᖏᑦ,
  ᑭᓇᐅᔭᕈᓐᓃᕐᓂᕐᒥᒃ ᐊᑕᐅᓯᖅ-ᐃᓚᐅᔪᖅ-ᐊᑕᐅᓯᖅ-ᓂᕈᐊᕐᓂᖅ, ᑐᓂᕐᕈᑎᑐᐃᓐᓇᕐᓂᒃ ᑮᓇᐅᔭᕈᑎᑦ, ᐊᒻᒪᓗ 7-ᐃᒃᓯᕙᐅᑕᒃ
  ᑲᑎᒪᔨᒃᑯᑦ 4-ᐅᓪᓗᑎᒃ-7-ᒥᑦ ᑮᓇᐅᔭᕈᑎᓂᒃ ᐊᓯᐅᔨᕝᕕᐅᓂᕐᒥᒃ ᒪᑭᒪᑎᑦᑎᔪᑦ — ᐊᖏᔪᖅᑳᖃᖏᑦᑐᖅ, ᐊᐅᓚᑦᑎᔨᖃᖏᑦᑐᖅ.
- **ᑭᒃᑯᓄᑦ** — ᐃᓚᒌᑦ, ᐃᑲᔪᖅᑎᒌᒃᑐᑦ ᐱᓕᕆᕝᕕᐃᑦ, ᑭᓇᐅᔭᕈᓐᓃᕐᓂᕐᒥᒃ ᓄᓇᓕᑦ, DAO-ᑦ **ᐃᓚᒋᔭᐅᓂᕐᒥᒃ** ᐱᔪᒪᔪᑦ
  ᐊᑭᓕᖅᓱᐃᓂᐅᖏᑦᑐᒥᒃ, ᐊᒻᒪᓗ ᑭᓇᑐᐃᓐᓇᖅ ᐱᔭᕆᐊᖃᖅᑐᖅ **ᓱᓕᔪᒥᒃ ᑭᓇᐅᔭᕈᓐᓃᕐᓂᕐᒥᒃ** ᐃᓚᐅᔪᓄᑦ.
- **ᖃᓄᖅ ᐊᑐᕐᓗᒍ** — ᑖᕝᕗᖓ ᐃᒡᓗᕈᓯᖅ ᐊᒥᓱᕈᕐᓗᒍ, ᑲᑎᒪᔨᒃᑯᓂᒃ ᐃᒃᓯᕙᐅᑎᓪᓗᒋᑦ, ᑲᑎᙵᕝᕕᖕᒥᒃ ᒪᑐᐃᕐᓗᒍ, ᐊᒻᒪᓗ
  ᐃᓚᐅᔪᑦ ᐃᓚᓕᐅᑦ ᑭᓇᐅᔭᕈᓐᓃᕐᓂᕐᒥᒃ ᐊᖏᕈᑎᑎᒍᑦ. ᑕᑯᓗᒍ [ᓱᒃᑲᔪᒃᑯᑦ ᐱᒋᐊᕐᓂᖅ](#-sukkajukkut-pigiarniq).

> *Ayni* (Quechua): ᑖᓐᓇ ᐊᖏᔪᖅ ᐅᑎᖅᑎᑦᑎᓂᖅ ᑐᓂᓂᕐᒥᒃ ᐊᒻᒪᓗ ᐱᓂᕐᒥᒃ — ᐃᒻᒥᓂᒃ-ᐃᑲᔪᕐᓂᖅ, ᐊᑕᐅᓯᖅ
