### Notes on a couple of requests
- **"Indian"** → rendered as **Hindi** (`hi`), India's most-spoken language. India
  has 20+ official languages; tell us if you want others (Tamil, Bengali, Telugu…).
- **"Bahasa"** → rendered as **Bahasa Indonesia** (`id`). Malay (`ms`) is closely
  related; ask if you'd prefer it.
- **Quechua** is fitting — *Ayni* itself is a Quechua word.

### Conventions for translators
- Translate **prose only**. Keep verbatim: code blocks, shell commands, badges,
  file paths/links (`IMPLEMENTATION.md`, etc.), proper nouns (**Ayni**, **AHA**,
  **Solana**, **Circle**, **Council**), and the ASCII diagrams (you may translate
  the captions beside them).
- Keep the heading structure and emoji so links and layout stay consistent.
- One file per language: `README.<code>.md`.
