## Ayni гэж юу вэ?

Ayni бол **нэргүй Төвлөрлийг сааруулсан Автономит Байгууллага (DAO)**-ын Solana хэрэгжүүлэлт юм — анх **AHA (Ancestral Humanity Anonymous)**-ийн хэрэгцээг хангахаар бүтээгдсэн боловч ямар ч байгууллагад нээлттэй. Угтаа энэ нь **AA / 12 алхамт уламжлал**-ын зуун жилээр батлагдсан амжилт дээр загварчилсан, дэлхий нийтийн нөхөрлөлүүдэд зориулсан гинжээс хамааралгүй загвар юм. Энэ нь аль ч бүлэгт **гишүүдийг элсүүлэх, сан хөмрөгтэй байх, бүлгийн ухамсараар шийдвэр гаргах, алдсан түлхүүрээ сэргээх** бэлэн арга замыг олгодог — харин гишүүн бүр тэг мэдлэгийн нотолгооны тусламжтайгаар **анхдагчаар нэрээ нууцалсан** хэвээр үлддэг.

- **Юу хийдэг вэ** — гишүүнчлэлийн нөхөрлөлийг гинжин дээр ажиллуулдаг: сэтгэлд холбоотой жил тутмын гишүүнчлэл, нэргүй нэг гишүүн-нэг санал, зөвхөн хандивын сан хөмрөг, 4/7-гийн түлхүүр сэргээлттэй 7 суудалтай Зөвлөл — эзэнгүй, админ түлхүүргүй.
- **Хэнд зориулсан бэ** — нөхөрлөлүүд, харилцан туслалцааны бүлгүүд, нэргүй нийгэмлэгүүд, таамаглалын оронд *харьяалал*-ыг хүсдэг DAO-ууд, мөн гишүүддээ **жинхэнэ нууцлал** хэрэгтэй хэн бүхэнд.
- **Хэрхэн ашиглах вэ** — загварыг fork хийж, Зөвлөл суулгаж, Тойрог (Circle) нээгээд, гишүүд хувийн амлалтаар (commitment) элснэ. [Хурдан эхлэх](#-хурдан-эхлэх)-ийг үзнэ үү.

> *Ayni* (Кечуа хэл): өгөх ба авахын ариун харилцан туслалцаа — өөрийгөө дэмжих, нэг гишүүн нэг дуу хоолой, төвлөрсөн эзэнгүй.

## ✨ Онцлогууд

- 🪪 **Сэтгэлд холбоотой гишүүнчлэл (soulbound)** — жил тутмын, шилжүүлэх боломжгүй. Харьяалал нь олж авч, шинэчлэгддэг болохоос хэзээ ч худалдаж авч, зарагддаггүй.
- 🕶️ **Анхдагчаар нэргүй** — гишүүн гэдэг нь харагдах хэтэвч биш, Merkle олонлог дахь хувийн амлалт юм. Санал хураалт болон итгэмжлэлүүд нь тэг мэдлэгийн; биеийн байдал зөвхөн сонголтоор задрана.
- 🗳️ **Бүлгийн ухамсрын санал хураалт** — нэг гишүүн, нэг санал, нэргүйгээр өгөгдөнө (токеноор жигнэсэн плутократ биш), давхар санал өгөхөөс сэргийлэх санал тус бүрийн nullifier-тэй.
- 🏛️ **Эзэнгүй, админ түлхүүргүй** — 7 суудалтай Зөвлөл *нь* эрх мэдэл бөгөөд зөвхөн **4/7**-оор үйлддэг.
- 🔑 **Алдагдлыг даван туулдаг түлхүүр сэргээлт** — суудлыг эргүүлэх эсвэл алдсан хэтэвчний бүх артефактыг шинэ хэтэвч рүү шилжүүлэх, аливаа нэг шударга суудал эхлүүлж чадах маргаан гаргах хугацааны цаана.
- 🌱 **Fork хийж болох Тойргууд** — аль ч бүлэг ижил засаглалтай шинэ Тойрог байгуулна; World Service Circle (Дэлхийн Үйлчилгээний Тойрог) хуваалцсан материалыг зохицуулдаг болохоос захирдаггүй.
- 📜 **Сонгомол задруулалттай итгэмжлэлүүд** — сургалт/эхлэлийн гэрчилгээ ("хэн, ямар сургалт, хэн заасан, хэзээ") тэг мэдлэгээр *талбар тус бүрээр* нээгддэг.

## 💡 Хэрхэн нэгддэг вэ

Үүнийг мод мэт уншина уу — хүмүүс нь дээд талын навчит титэм, Тойргууд нь мөчирүүд, World Service Circle нь ёроолд байх их бие ба үндэс юм:

```
 member member member      member member member      member member member     ← the members
 (anon) (anon) (anon)      (anon) (anon) (anon)      (anon) (anon) (anon)         (anonymous,
    \      |      /          \      |      /          \      |      /              one member,
     ┌─────┬─────┐            ┌─────┬─────┐            ┌─────┬─────┐               one vote)
     │   Cusco   │            │  Lisbon   │            │  Bangkok  │
     │ Council 7 │            │ Council 7 │            │ Council 7 │   …        ← Circles: the
     └─────┴─────┘            └─────┴─────┘            └─────┴─────┘               branches
           └────────────────────────┬────────────────────────┘
                                    │   every Circle is forked from one shared template
                     ┌───────────────┴───────────────┐
                     │     WORLD SERVICE CIRCLE       │   ← the trunk / root ("foundation"):
                     │   12 Steps · Preamble · docs   │      holds the shared template + a
                     │    7-seat Council · 4-of-7     │      Council (4/7) that coordinates
                     └───────────────────────────────┘      but does NOT govern
```

- **Гишүүд (титэм)** — тус бүр нь Тойргийн гишүүдийн олонлогт нэргүй амлалт болж нэгдэж, нотолгоогоор үйлддэг; хэтэвчээ хэзээ ч ил гаргах шаардлагагүй. Нэг гишүүн, нэг санал.
- **Тойргууд (мөчирүүд)** — өөрийн 7 суудалтай Зөвлөл, сан хөмрөг, санал хураалттай бие даасан орон нутгийн бүлгүүд; загвараас fork хийгдсэн.
- **World Service Circle (их бие/үндэс)** — хуваалцсан загвар, баримтуудыг хадгалж, Тойрог үүсгэхийг зохицуулдаг боловч орон нутгийн бүлгийн ухамсрыг **дарж захирдаггүй**. Энэхүү холбоос нь захирах гинж биш, *холбооны холбоос (federation link)* юм.

## 🎩 Хэн юу хийдэг вэ — 7 суудалтай Зөвлөл

```
                          THE COUNCIL  (7 seats · acts by 4-of-7 · IS the authority)
   ┌──────────────────────── 3 functional servants ────────────────────────┐
   │                                                                        │
   │   TREASURER          SECRETARY            RHYTHM KEEPER                 │
   │   stewards the       admits members,      keeps the cadence of         │
   │   treasury &         records & docs,      meetings/ceremonies;         │
   │   soulbound mint     proposal hygiene     the reference / lead seat    │
   │                                                                        │
   └────────────────────────────────────────────────────────────────────────┘
   ┌──────────────────────── 4 elders of the directions ───────────────────┐
   │                                                                        │
   │   ELDER NORTH      ELDER EAST       ELDER SOUTH       ELDER WEST        │
   │   no daily duty — their role is quorum & resilience, so recovery       │
   │   never depends on the three busy servants alone (medicine wheel)      │
   │                                                                        │
   └────────────────────────────────────────────────────────────────────────┘

   MEMBERS  ──one-member-one-vote (anonymous, ZK)──▶  group-conscience decisions
            the Council serves and recovers; the membership decides direction
```

- **Админ түлхүүргүй.** Бүх давуу эрхтэй үйлдэл нь Зөвлөлийн суудлын үүрэг эсвэл 4/7-гийн санал юм.
- **Үйлчлэгчид үйлчилдэг, гишүүд шийддэг.** Тогтмол үүргүүд нь суудалд шилжүүлэгдэж, Зөвлөлийн эргэлтээр цуцлагдах боломжтой; чиглэлийг гишүүдийн санал тогтооно.

## 📖 Хэрэглээ ба жишээ

Ayni-ийн дэмждэг дөрвөн төрлийн шийдвэр, тус бүр нь хаана амьдардаг:

| Шийдвэр | Хэн санал өгдөг | Механизм |
|---|---|---|
| **Орон нутгийн асуудал** (Тойргийн өөрийн хэрэг) | тухайн Тойргийн гишүүд | нэргүй ZK гишүүний санал |
| **Сангийн дүрэм** (жнь "12 Алхам") | зөвхөн сангийн түвшний түлхүүрүүд | World Service гишүүн/Зөвлөлийн санал |

| **Сэргээлт / сан хөмрөг** | 7 суудалтай Зөвлөл | 4/7-гийн санал + маргаан гаргах хугацаа |

## 🚀 Хурдан эхлэх

> Урьдчилсан шаардлага: **Rust**, **Solana/Agave CLI 2.x**, **Anchor 0.31.1**, **Node 20+**, мөн (нотолгоонд) **circom 2.1** + **snarkjs**.

```bash
# 1. clone
git clone https://github.com/Ayniator/Ayni.git && cd Ayni

# 2. install JS deps (proving helpers + tests)
npm install

# 3. build the on-chain program
anchor build

# 4. run the test suite (localnet: memberships, 4-of-7 recovery, a real ZK vote round-trip)
anchor test
```

Энэ бол анхны ажиллагааны бүх зүйл. Тестүүд нь Тойрог босгож, нэргүй гишүүнчлэл олгож, 4/7-гийн сэргээлт ажиллуулж, бодит Groth16 саналын нотолгоог гинжин дээр баталгаажуулдаг (мөн дахин тоглуулсан nullifier-ийг татгалздаг).

Өөрийн нөхөрлөлийг босгож, дөрвөн төрлийн санал хураалтыг бүгдийг нь ажиллуулахын тулд **[IMPLEMENTATION.md](../IMPLEMENTATION.md)**-г алхам алхмаар дагана уу.

## 🤝 Хувь нэмэр оруулах

Хувь нэмэр оруулахыг урьж байна — ялангуяа асуудлууд (issues), PR-ууд, мөн криптографийн хяналт.

1. Fork хийж, `solana`-аас салбарлана (анхдагч салбар; бусад гинжүүд `ethereum`, `avalanche` дээр байдаг).
2. `anchor build && anchor test` амжилттай дамжих ёстой.
3. Өөрчлөлт болон түүний аюулгүй байдалд үзүүлэх нөлөөг тайлбарласан PR нээ.

Эхлэх сайн газрууд нь **`good first issue`** гэж шошголсон байдаг. Бие биедээ найрсаг хандаарай — [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md)-г үзнэ үү.

**Санал болгосон GitHub сэдвүүд:** `solana` · `anchor` · `zero-knowledge` · `zk-snarks` · `circom` · `dao` · `governance` · `soulbound` · `privacy` · `anonymous-voting` · `groth16`
