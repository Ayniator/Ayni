## Ayni ဆိုသည်မှာ ဘာနည်း။

Ayni သည် **အမည်မဖော် ဗဟိုချုပ်ကိုင်မှုကင်းသော အလိုအလျောက်အုပ်ချုပ်သည့် အဖွဲ့အစည်း (DAO)** ၏ Solana အကောင်အထည်ဖော်မှုဖြစ်သည် — မူလက **AHA (Ancestral Humanity Anonymous)** ၏ လိုအပ်ချက်များကို ဖြည့်ဆည်းရန် ဒီဇိုင်းပြုလုပ်ထားသော်လည်း မည်သည့်အဖွဲ့အစည်းအတွက်မဆို ပွင့်လင်းသည်။ အနှစ်သာရအားဖြင့် ၎င်းသည် **AA / 12-အဆင့် ထုံးတမ်းစဉ်လာများ** ၏ ရာစုနှစ်တစ်ခုစာ သက်သေပြထားသော အောင်မြင်မှုကို နမူနာယူထားသည့် ကမ္ဘာတစ်ဝန်း အသင်းအဖွဲ့များအတွက် chain-မရွေး template တစ်ခုဖြစ်သည်။ ၎င်းသည် မည်သည့်အဖွဲ့ကိုမဆို **အသင်းဝင်များ လက်ခံရန်၊ ဘဏ္ဍာငွေထိန်းသိမ်းရန်၊ အဖွဲ့စိတ်ဓာတ်ဖြင့် ဆုံးဖြတ်ရန်နှင့် ပျောက်ဆုံးသွားသော သော့များမှ ပြန်လည်ထူထောင်ရန်** အသင့်ပြုလုပ်ထားသော နည်းလမ်းတစ်ခုပေးသည် — အသင်းဝင်တိုင်းသည် zero-knowledge proof များဖြင့် **မူရင်းအတိုင်း အမည်မဖော်ဘဲ** ရှိနေသည်။

- **ဘာလုပ်ဆောင်သလဲ** — chain ပေါ်တွင် အသင်းအဖွဲ့ဝင်ခွင့်ကို လည်ပတ်စေသည်: နှစ်စဉ် soulbound အသင်းဝင်ခွင့်များ၊ အမည်မဖော် အသင်းဝင်တစ်ဦးတစ်မဲ၊ လှူဒါန်းမှုသာ ဘဏ္ဍာငွေတိုက်နှင့် 4-of-7 သော့ပြန်လည်ထူထောင်ခြင်းပါသည့် ၇-နေရာ ကောင်စီ — ပိုင်ရှင်မရှိ၊ admin သော့မရှိ။
- **ဘယ်သူ့အတွက်လဲ** — အသင်းအဖွဲ့များ၊ အပြန်အလှန်ကူညီရေးအဖွဲ့များ၊ အမည်မဖော် အသိုက်အဝန်းများ၊ ကြို့ကမ်းရောင်းဝယ်မှုအစား **သက်ဆိုင်မှု** ကို လိုလားသော DAO များနှင့် အသင်းဝင်များအတွက် **စစ်မှန်သော ကိုယ်ရေးလုံခြုံမှု** လိုအပ်သူတိုင်း။
- **ဘယ်လိုအသုံးပြုမလဲ** — template ကို fork လုပ်ပါ၊ ကောင်စီတစ်ခုဖွဲ့ပါ၊ Circle (အသင်းအဝိုင်း) တစ်ခုဖွင့်ပါ၊ အသင်းဝင်များသည် ကိုယ်ရေးကိုယ်တာ commitment များအဖြစ် ဝင်ရောက်ကြသည်။ [အမြန်စတင်ခြင်း](#-quick-start) ကို ကြည့်ပါ။

> *Ayni* (Quechua ဘာသာ): ပေးခြင်းနှင့် ရယူခြင်း၏ မြင့်မြတ်သော အပြန်အလှန်မျှဝေမှု — မိမိကိုယ်ကို ထောက်ပံ့ခြင်း၊ အသင်းဝင်တစ်ဦးတစ်အသံ၊ ဗဟိုပိုင်ရှင်မရှိ။

## ✨ အင်္ဂါရပ်များ

- 🪪 **Soulbound အသင်းဝင်ခွင့်** — နှစ်စဉ်၊ လွှဲပြောင်း၍မရ။ သက်ဆိုင်မှုကို ရရှိ၍ ပြန်လည်သက်တမ်းတိုးရသည်၊ ဘယ်သောအခါမှ ဝယ်ယူ သို့မဟုတ် ရောင်းချ၍မရ။
- 🕶️ **မူရင်းအတိုင်း အမည်မဖော်** — အသင်းဝင်တစ်ဦးသည် မြင်သာသော wallet မဟုတ်ဘဲ Merkle set အတွင်းရှိ ကိုယ်ရေးကိုယ်တာ commitment တစ်ခုဖြစ်သည်။ မဲပေးခြင်းနှင့် အထောက်အထားများသည် zero-knowledge ဖြစ်၍ ဝိသေသလက္ခဏာကို ရွေးချယ်မှသာ ဖော်ထုတ်သည်။
- 🗳️ **အဖွဲ့စိတ်ဓာတ် မဲပေးခြင်း** — အသင်းဝင်တစ်ဦး၊ မဲတစ်မဲ၊ အမည်မဖော်ဘဲ ပေးသည် (token-အလေးချိန်ပေးသည့် ပလူတိုကရေစီမရှိ)၊ နှစ်ထပ်မဲကို ကာကွယ်ရန် အဆိုတစ်ခုလျှင် nullifier တစ်ခုဖြင့်။
- 🏛️ **ပိုင်ရှင်မရှိ၊ admin သော့မရှိ** — ၇-နေရာ ကောင်စီ *သည်ပင်လျှင်* အာဏာပိုင်ဖြစ်၍ **4-of-7** ဖြင့်သာ ဆောင်ရွက်သည်။
- 🔑 **ဆုံးရှုံးမှုကို ခံနိုင်သော သော့ပြန်လည်ထူထောင်ခြင်း** — နေရာတစ်ခုကို လှည့်ပြောင်းခြင်း သို့မဟုတ် ပျောက်ဆုံးသွားသော wallet ၏ artifact တိုင်းကို အသစ်တစ်ခုသို့ ရွှေ့ပြောင်းခြင်း၊ ရိုးသားသော နေရာတစ်ခုတည်းက ဖြုတ်ချနိုင်သည့် ကန့်ကွက်ချိန်ကာလ၏ နောက်ကွယ်တွင်။
- 🌱 **Fork လုပ်နိုင်သော Circle များ** — မည်သည့်အဖွဲ့မဆို တူညီသော အုပ်ချုပ်ရေးဖြင့် Circle အသစ်တစ်ခုကို စတင်နိုင်သည်၊ World Service Circle (ကမ္ဘာ့ဝန်ဆောင်မှု အသင်းအဝိုင်း) သည် မျှဝေသုံးသော အကြောင်းအရာများကို ညှိနှိုင်းသည်၊ မအုပ်စိုးပါ။
- 📜 **ရွေးချယ်ဖွင့်ဟ အထောက်အထားများ** — သင်တန်း/ဝင်ခွင့်လက်မှတ်များ ("မည်သူ၊ မည်သည့်သင်တန်း၊ မည်သူသင်ကြားပေးသည်၊ မည်သည့်အချိန်") ကို zero-knowledge ဖြင့် *အကွက်တစ်ခုချင်းစီ* ဖွင့်ဟသည်။

## 💡 မည်သို့ အစုအဖွဲ့လိုက် အံဝင်ခွင်ကျဖြစ်သလဲ

၎င်းကို သစ်ပင်တစ်ပင်ကဲ့သို့ ဖတ်ပါ — လူများသည် အပေါ်ဆုံးရှိ အရွက်များ၊ Circle များသည် အကိုင်းအခက်များ၊ World Service Circle သည် အောက်ခြေရှိ ပင်စည်နှင့် အမြစ်များဖြစ်သည်:

```
 member member member      member member member      member member member     ← the members
 (anon) (anon) (anon)      (anon) (anon) (anon)      (anon) (anon) (anon)         (anonymous,
    \      |      /          \      |      /          \      |      /              one member,
     ┌─────┬─────┐            ┌─────┬─────┐            ┌─────┬─────┐               one vote)
     │   Cusco   │            │  Lisbon   │            │  Bangkok  │
     │ Council 7 │            │ Council 7 │            │ Council 7 │   …        ← Circles: the
     └─────┴─────┘            └─────┴─────┘            └─────┴─────┘               branches
           └────────────────────────┬────────────────────────┘
                                    │   every Circle is forked from one shared template
                     ┌───────────────┴───────────────┐
                     │     WORLD SERVICE CIRCLE       │   ← the trunk / root ("foundation"):
                     │   12 Steps · Preamble · docs   │      holds the shared template + a
                     │    7-seat Council · 4-of-7     │      Council (4/7) that coordinates
                     └───────────────────────────────┘      but does NOT govern
```

- **အသင်းဝင်များ (အရွက်များ)** — တစ်ဦးချင်းစီသည် Circle တစ်ခု၏ အသင်းဝင်အစုထဲသို့ အမည်မဖော် commitment တစ်ခုအဖြစ် ဝင်ရောက်၍ proof များမှတစ်ဆင့် ဆောင်ရွက်သည်၊ wallet ကို ဘယ်သောအခါမှ ဖော်ထုတ်ရန်မလို။ အသင်းဝင်တစ်ဦး၊ မဲတစ်မဲ။
- **Circle များ (အကိုင်းအခက်များ)** — ကိုယ်ပိုင်အုပ်ချုပ်သော ဒေသခံအဖွဲ့များ၊ တစ်ခုစီတွင် ကိုယ်ပိုင် ၇-နေရာ ကောင်စီ၊ ဘဏ္ဍာငွေတိုက်နှင့် မဲများရှိသည်၊ template မှ fork လုပ်ထားသည်။
- **World Service Circle (ပင်စည်/အမြစ်)** — မျှဝေသုံးသော template နှင့် စာရွက်စာတမ်းများကို ထိန်းသိမ်း၍ Circle ဖန်တီးခြင်းကို ညှိနှိုင်းသည်၊ သို့သော် ဒေသခံ အဖွဲ့စိတ်ဓာတ်ကို **မလွှမ်းမိုး**။ ဆက်သွယ်မှုသည် အမိန့်ပေးကွင်းဆက်မဟုတ်ဘဲ *ဖက်ဒရေးရှင်း ဆက်သွယ်မှု* ဖြစ်သည်။

   │   no daily duty — their role is quorum & resilience, so recovery       │

- **Admin သော့မရှိ။** အခွင့်ထူးခံ လုပ်ဆောင်ချက်တိုင်းသည် ကောင်စီနေရာ၏ တာဝန် သို့မဟုတ် 4-of-7 အဆိုတစ်ခုဖြစ်သည်။
- **ဝန်ထမ်းများက အမှုထမ်းသည်၊ အသင်းဝင်များက ဆုံးဖြတ်သည်။** ပုံမှန်တာဝန်များကို နေရာတစ်ခုသို့ လွှဲအပ်၍ ကောင်စီ လှည့်ပြောင်းခြင်းဖြင့် ပြန်ရုပ်သိမ်းနိုင်သည်၊ ဦးတည်ချက်ကို အသင်းဝင်မဲဖြင့် သတ်မှတ်သည်။

| ဆုံးဖြတ်ချက် | မည်သူ မဲပေးသလဲ | ယန္တရား |
|---|---|---|
| **ဒေသဆိုင်ရာ ကိစ္စ** (Circle တစ်ခု၏ ကိုယ်ပိုင်လုပ်ငန်း) | ထို Circle ၏ အသင်းဝင်များ | အမည်မဖော် ZK အသင်းဝင်မဲ |

## 🚀 အမြန်စတင်ခြင်း

> လိုအပ်ချက်များ: **Rust**၊ **Solana/Agave CLI 2.x**၊ **Anchor 0.31.1**၊ **Node 20+** နှင့် (proof များအတွက်) **circom 2.1** + **snarkjs**။

```bash
# 1. clone
git clone https://github.com/Ayniator/Ayni.git && cd Ayni

# 2. install JS deps (proving helpers + tests)
npm install

# 3. build the on-chain program
anchor build

# 4. run the test suite (localnet: memberships, 4-of-7 recovery, a real ZK vote round-trip)
anchor test
```

ဤသည်ပင် ပထမဆုံးအကြိမ်လည်ပတ်မှု အပြည့်အစုံဖြစ်သည်။ test များသည် Circle တစ်ခုကို တည်ဆောက်၍ အမည်မဖော် အသင်းဝင်ခွင့်များ ထုတ်ပေး၊ 4-of-7 ပြန်လည်ထူထောင်ခြင်းကို လည်ပတ်ပြီး chain ပေါ်တွင် စစ်မှန်သော Groth16 မဲ proof ကို အတည်ပြုသည် (ပြန်ဖွင့်သော nullifier ကို ငြင်းပယ်သည်)။

သင့်ကိုယ်ပိုင် အသင်းအဖွဲ့ကို တည်ဆောက်၍ မဲလေးမျိုးလုံးကို လည်ပတ်ရန် **[IMPLEMENTATION.md](../IMPLEMENTATION.md)** ကို အဆင့်ဆင့်လိုက်နာပါ။
