## Что такое Ayni?

Ayni — это реализация на Solana **анонимной децентрализованной автономной организации (DAO)** —
изначально разработанная под нужды **AHA (Ancestral Humanity Anonymous)**, но открытая для любой
организации. По своей сути это шаблон, не привязанный к конкретному блокчейну, для всемирных
содружеств, построенный по образцу проверенного веком успеха **традиций AA / 12 шагов**. Он даёт
любой группе готовый способ **принимать членов, держать казну, принимать решения по совести группы
и восстанавливаться после утраты ключей** — при этом каждый член остаётся **анонимным по умолчанию**
благодаря доказательствам с нулевым разглашением.

- **Что он делает** — управляет членским содружеством on-chain: soulbound годовое членство,
  анонимное «один член — один голос», казна только для пожертвований и Совет из 7 мест с
  восстановлением ключей по схеме 4 из 7 — без владельца, без админ-ключа.
- **Для кого он** — для содружеств, групп взаимопомощи, анонимных сообществ, DAO, которым нужна
  *причастность* вместо спекуляции, и для всех, кому нужна **настоящая приватность** для своих членов.
- **Как им пользоваться** — форкните шаблон, посадите Совет, откройте Circle, и члены присоединяются
  как приватные обязательства (commitments). См. [Быстрый старт](#-быстрый-старт).

> *Ayni* (кечуа): священная взаимность давания и получения — самоподдержка, один член — один голос,
> без центрального владельца.

## ✨ Возможности

- 🪪 **Soulbound-членство** — годовое, непередаваемое. Причастность заслуживается и обновляется,
  её никогда не покупают и не продают.
- 🕶️ **Анонимность по умолчанию** — член это приватное обязательство в множестве Меркла, а не
  видимый кошелёк. Голосование и удостоверения работают с нулевым разглашением; личность
  раскрывается только по выбору.
- 🗳️ **Голосование по совести группы** — один член, один голос, поданный анонимно (никакой
  плутократии, взвешенной по токенам), с нуллификатором на каждое предложение, предотвращающим
  двойное голосование.
- 🏛️ **Без владельца, без админ-ключа** — Совет из 7 мест *и есть* власть, и действует только по
  схеме **4 из 7**.
- 🔑 **Восстановление ключей, переживающее их утрату** — ротация места или миграция любого артефакта
  утраченного кошелька на новый, за окном оспаривания, которое может включить любое одно честное место.
- 🌱 **Форкаемые Circle** — любая группа разворачивает новый Circle с идентичным управлением;
  World Service Circle координирует общие материалы, а не правит.
- 📜 **Удостоверения с избирательным раскрытием** — сертификаты о курсах/посвящениях («кто, какой
  курс, кем преподан, когда»), раскрываемые *поле за полем* с нулевым разглашением.

## 💡 Как всё это складывается воедино

Читайте это как дерево — люди это крона наверху, Circle это ветви, а World Service Circle это
ствол и корни у основания:

```
 member member member      member member member      member member member     ← the members
 (anon) (anon) (anon)      (anon) (anon) (anon)      (anon) (anon) (anon)         (anonymous,
    \      |      /          \      |      /          \      |      /              one member,
     ┌─────┬─────┐            ┌─────┬─────┐            ┌─────┬─────┐               one vote)
     │   Cusco   │            │  Lisbon   │            │  Bangkok  │
     │ Council 7 │            │ Council 7 │            │ Council 7 │   …        ← Circles: the
     └─────┴─────┘            └─────┴─────┘            └─────┴─────┘               branches
           └────────────────────────┬────────────────────────┘
                                    │   every Circle is forked from one shared template
                     ┌───────────────┴───────────────┐
                     │     WORLD SERVICE CIRCLE       │   ← the trunk / root ("foundation"):
                     │   12 Steps · Preamble · docs   │      holds the shared template + a
                     │    7-seat Council · 4-of-7     │      Council (4/7) that coordinates
                     └───────────────────────────────┘      but does NOT govern
```

- **Члены (крона)** — каждый присоединяется к множеству членов Circle как анонимное обязательство и
  действует через доказательства; ему никогда не нужно раскрывать кошелёк. Один член, один голос.
- **Circle (ветви)** — автономные локальные группы, у каждой свой Совет из 7 мест, своя казна и свои
  голосования; форкнуты из шаблона.
- **World Service Circle (ствол/корень)** — держит общий шаблон и документы и координирует создание
  Circle, но **не** перекрывает совесть локальной группы. Связь это *федеративная связь*, а не цепочка
  командования.

## 🎩 Кто что делает — Совет из 7 мест

```
                          THE COUNCIL  (7 seats · acts by 4-of-7 · IS the authority)
   ┌──────────────────────── 3 functional servants ────────────────────────┐
   │                                                                        │
   │   TREASURER          SECRETARY            RHYTHM KEEPER                 │
   │   stewards the       admits members,      keeps the cadence of         │
   │   treasury &         records & docs,      meetings/ceremonies;         │
   │   soulbound mint     proposal hygiene     the reference / lead seat    │
   │                                                                        │
   └────────────────────────────────────────────────────────────────────────┘
   ┌──────────────────────── 4 elders of the directions ───────────────────┐
   │                                                                        │
   │   ELDER NORTH      ELDER EAST       ELDER SOUTH       ELDER WEST        │
   │   no daily duty — their role is quorum & resilience, so recovery       │
   │   never depends on the three busy servants alone (medicine wheel)      │
   │                                                                        │
   └────────────────────────────────────────────────────────────────────────┘

   MEMBERS  ──one-member-one-vote (anonymous, ZK)──▶  group-conscience decisions
            the Council serves and recovers; the membership decides direction
```

- **Без админ-ключа.** Каждое привилегированное действие это обязанность места в Совете или
  предложение по схеме 4 из 7.
- **Служители служат, члены решают.** Рутинные обязанности делегируются месту и отзываются ротацией
  Совета; направление задаётся голосом членов.

## 📖 Использование и примеры

Четыре вида решений, которые поддерживает Ayni, и где каждое из них живёт:

| Решение | Кто голосует | Механизм |
|---|---|---|
| **Локальное дело** (внутреннее дело Circle) | члены данного Circle | анонимное ZK-голосование членов |
| **Устав фундамента** (например, «12 шагов») | только ключи уровня фундамента | голосование членов/Совета World Service |
| **Общий текст** (например, предлагаемая Преамбула) | **все** Circle + фундамент | агрегированное голосование по всей федерации |
| **Восстановление / казна** | Совет из 7 мест | предложение 4 из 7 + окно оспаривания |

Проработанные, готовые к копированию пошаговые руководства для всех этих случаев находятся в
**[IMPLEMENTATION.md](../IMPLEMENTATION.md)**.

## 🚀 Быстрый старт

> Требования: **Rust**, **Solana/Agave CLI 2.x**, **Anchor 0.31.1**, **Node 20+** и (для доказательств)
> **circom 2.1** + **snarkjs**.

```bash
# 1. clone
git clone https://github.com/Ayniator/Ayni.git && cd Ayni

# 2. install JS deps (proving helpers + tests)
npm install

# 3. build the on-chain program
anchor build

# 4. run the test suite (localnet: memberships, 4-of-7 recovery, a real ZK vote round-trip)
anchor test
```

Это весь первый запуск. Тесты поднимают Circle, выпускают анонимные членства, выполняют
восстановление 4 из 7 и проверяют настоящее доказательство голосования Groth16 on-chain
(а также отклоняют повторно использованный нуллификатор).

Чтобы поднять собственное содружество и запустить все четыре вида голосования, следуйте
**[IMPLEMENTATION.md](../IMPLEMENTATION.md)** шаг за шагом.

## 🤝 Вклад в проект

Вклад приветствуется — особенно issue, PR и ревью криптографии.

1. Форкните и создайте ветку от `solana` (ветка по умолчанию; другие блокчейны живут на `ethereum`, `avalanche`).
2. `anchor build && anchor test` должны проходить.
3. Откройте PR с описанием изменения и его влияния на безопасность.

Хорошие места для старта помечены меткой **`good first issue`**. Будьте друг к другу на высоте —
см. [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md).

**Рекомендуемые GitHub-темы:** `solana` · `anchor` · `zero-knowledge` · `zk-snarks` · `circom` ·
`dao` · `governance` · `soulbound` · `privacy` · `anonymous-voting` · `groth16`
