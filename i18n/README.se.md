## Mii lea Ayni?

Ayni lea **anonyma Decentraliserejuvvon Autonoma Organisašuvnna (DAO)** Solana-implementašuvdna —
álgoálggus hábmejuvvon dustet **AHA (Ancestral Humanity Anonymous)** dárbbuid, muhto rabas vaikko
guđege organisašuvdnii. Vuođustusas dat lea čađđa-agnostalaš málle máilmmiviidosaš searvvušiidda,
mii lea hábmejuvvon **AA / 12-lávkki árbevieruid** jahkečuođi duođaštuvvon lihkostuvvama mielde. Dat
addá vaikko guđege jovkui válmmaš vuogi **váldit miellahtuid, doallat reaiddubeavstti, mearridit
joavkooamedovddu mielde, ja oažžut ruovttoluotta láhppojuvvon čoavttagiid** — seammás go juohke
miellahttu bissu **anonyma standárddan** nolla-máhtu duođaštusaid bokte.

- **Maid dat dahká** — vuodjá searvvuš-miellahttodaga čađa-alde: sieludulvejuvvon jahkásaš
  miellahttovuođaid, anonyma okta-miellahttu-okta-jietna, attáldat-dušše reaiddubeavstti, ja 7-saji
  Ráđi 4:s-7:s čoavddaoaožžumiin — eaiggáhis, eaige hálddašeaddjičoavddagis.
- **Geasa dat lea** — searvvušiidda, lonohallanveahki joavkkuide, anonyma searvvušiidda, DAO:aide mat
  háliidit *gullevašvuođa* spekulašuvnna sajis, ja vaikko geasa gii dárbbaša **duohta priváhtavuođa**
  miellahtuide.
- **Mo dan geavahit** — máŋge málle, válljes Ráđi, raba Searvvi (Circle), ja miellahtut servet
  priváhta geatnegasvuohtan. Geahča [Jođánis álgu](#-quick-start).

> *Ayni* (Quechua): addima ja vuostáiváldima bassi máhcahallan — iešdoarjja, okta miellahttu okta
> jietna, ii guovddáš eaiggát.

## ✨ Iešvuođat

- 🪪 **Sieludulvejuvvon miellahttovuohta** — jahkásaš, ii-sirdojuvvon. Gullevašvuohta dinejuvvo ja
  ođasmahttojuvvo, ii goassege oastojuvvo dahje vuvdojuvvo.
- 🕶️ **Anonyma standárddan** — miellahttu lea priváhta geatnegasvuohta Merkle-joavkkus, ii oidnosis
  leahkki burssa. Jienasteapmi ja duođaštusat leat nolla-máhtu; identitehta almmuhuvvo dušše
  válljema mielde.
- 🗳️ **Joavkooamedovddu jienasteapmi** — okta miellahttu, okta jietna, addojuvvon anonymalaččat (ii
  token-deattuhuvvon pluttokratiija), juohke evttohusa nullifier:iin mii hehtte guovttegeardásaš
  jienasteami.
- 🏛️ **Ii eaiggát, ii hálddašeaddjičoavddat** — 7-saji Ráđđi *lea* eiseváldi ja doaibmá dušše
  **4:s-7:s**.
- 🔑 **Čoavddaoažžun mii ceavzá láhppoma** — jorat saji dahje sirdde juohke láhppojuvvon burssa
  artefávtta ođđasii, dakkár vuosttaldanlása duohken maid vaikko okta rehálaš sadji sáhttá vuolggahit.
- 🌱 **Máŋgejuvvon Searvvit** — vaikko guhtege joavku vuolggaha ođđa Searvvi seamma stivrejumiin;
  Máilmmibálvalus Searvi (World Service Circle) ovttastahttá oktasaš materiála, ii ráđđe.
- 📜 **Válljejeaddji-almmuheami duođaštusat** — kurssa/álgahallan-sertifikáhtat ("gii, guhte kursa,
  gii oahpahii, goas") rahpojuvvon *gieddi gieddái* nolla-máhtus.

## 💡 Mo dat heive oktii

Loga dan dego muora — olbmot leat latnja bajimusas, Searvvit leat ovssat, ja Máilmmibálvalus Searvi
lea ráŋga ja ruohttasat vuolimusas:

```
 member member member      member member member      member member member     ← the members
 (anon) (anon) (anon)      (anon) (anon) (anon)      (anon) (anon) (anon)         (anonymous,
    \      |      /          \      |      /          \      |      /              one member,
     ┌─────┬─────┐            ┌─────┬─────┐            ┌─────┬─────┐               one vote)
     │   Cusco   │            │  Lisbon   │            │  Bangkok  │
     │ Council 7 │            │ Council 7 │            │ Council 7 │   …        ← Circles: the
     └─────┴─────┘            └─────┴─────┘            └─────┴─────┘               branches
           └────────────────────────┬────────────────────────┘
                                    │   every Circle is forked from one shared template
                     ┌───────────────┴───────────────┐
                     │     WORLD SERVICE CIRCLE       │   ← the trunk / root ("foundation"):
                     │   12 Steps · Preamble · docs   │      holds the shared template + a
                     │    7-seat Council · 4-of-7     │      Council (4/7) that coordinates
                     └───────────────────────────────┘      but does NOT govern
```

- **Miellahtut (latnja)** — juohkehaš searvá Searvvi miellahttojovkui anonyma geatnegasvuohtan ja
  doaibmá duođaštusaid bokte; ii goassege dárbbaš almmuhit burssa. Okta miellahttu, okta jietna.
- **Searvvit (ovssat)** — autonoma báikkálaš joavkkut, juohke ieš 7-saji Ráđiin, reaiddubeavstti, ja
  jienastemiiguin; máŋgejuvvon málles.
- **Máilmmibálvalus Searvi (ráŋga/ruohtas)** — doallá oktasaš málle ja dokumeanttaid ja ovttastahttá
  Searvvi ráhkadeami, muhto **ii** badjelgeahča báikkálaš joavkooamedovddu. Liŋka lea
  *federašuvdna-liŋka*, ii gohččumiid gáhttu.

## 🚀 Jođánis álgu

> Ovdagáibádusat: **Rust**, **Solana/Agave CLI 2.x**, **Anchor 0.31.1**, **Node 20+**, ja
> (duođaštusaide) **circom 2.1** + **snarkjs**.

```bash
# 1. clone
git clone https://github.com/Ayniator/Ayni.git && cd Ayni

# 2. install JS deps (proving helpers + tests)
npm install

# 3. build the on-chain program
anchor build

# 4. run the test suite (localnet: memberships, 4-of-7 recovery, a real ZK vote round-trip)
anchor test
```

Dat lea olles vuosttaš-vuodjin. Testtat čatnet Searvvi, addet anonyma miellahttovuođaid, vudjet
4:s-7:s oažžuma, ja dárkkistit duohta Groth16 jienasteami čájáhusa čađa-alde (ja hilgot máhcahuvvon
nullifier:a).

Iežat searvvuša cegget ja vuodjit buot njeallje jienasteami lágan, čuovo
**[IMPLEMENTATION.md](../IMPLEMENTATION.md)** lávkkis lávkái.
